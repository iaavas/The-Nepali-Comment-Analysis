# The Nepali Comment Analysis

This project provides an insightful analysis of the YouTube statistics for the popular Nepali YouTube channel, **The Nepali Comment**. It uses Python libraries such as **pandas** for data manipulation and **plotly** for visualizations.

## Overview

The goal of this project is to extract YouTube data for **The Nepali Comment** channel and perform exploratory data analysis (EDA) to uncover trends and insights related to the channel’s video performance.

## Methodology

1. **Data Extraction**:
   - Extract video titles, number of likes, number of comments, and video descriptions using the **Google YouTube API**.

2. **Exploratory Data Analysis (EDA)**:
   - Perform data analysis using **pandas** to understand patterns and trends.
   - Visualize the findings using **plotly** for interactive charts and graphs.

## Requirements

- Python 3.x
- Google YouTube API credentials
- pandas
- plotly

## Setup Instructions

1. Clone this repository:
   ```bash
   git clone https://github.com/iaavas/The-Nepali-Comment-Analysis.git
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

3. Set up Google YouTube API credentials and add them to your project.

4. Run the script to start extracting data and performing analysis:

   ```bash
   python extract.py
   ```
